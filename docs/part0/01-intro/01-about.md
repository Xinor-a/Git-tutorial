# このチュートリアルについて

[Back to Index](../../../README.md) | [Next: Gitをインストールしよう >](../02-install/01-install-git.md)

## このチュートリアルはどんなもの？

Git を「コマンドの暗記」ではなく「なぜそうするのか」から理解するための、ストーリー型チュートリアルです。

各ページは実際の開発シナリオをもとに書かれています。
「こういう状況でこのコマンドを使う」という文脈で学ぶので、使い方が自然と身につきます。

## どう使えばいい？

**順番に読み進めてください。**
各ページは前のページの内容を前提に書かれています。
気になるページだけつまみ食いするよりも、最初から順に進むのがおすすめです。

**必ず手を動かしてください。**
読むだけで終わらせず、ターミナルでコマンドを実際に打ちながら進めましょう。
各ページの末尾に演習があります。面倒でも飛ばさないようにしてください。

**間違えても大丈夫です。**
演習の最後には、うまくいかなかったときの復帰手順が載っています。
失敗したらそこを読んでリセットして、もう一度やってみましょう。

## 2つのリポジトリについて

このチュートリアルでは、2つのリポジトリを使います。

| リポジトリ | 用途 |
|---|---|
| **git-tutorial**（このリポジトリ） | チュートリアル本文。今あなたが読んでいるページです |
| **git-collaborate** | Part 2 の演習で使う練習用リポジトリ。Part 2 に入ったらフォークして使います |

Part 2 に入るまでは **git-tutorial** だけを読んでいれば OK です。
